# Kannada Knowledge

An educational Flutter application dedicated to the rich history, literature, art, and geography of Karnataka. This app allows users to explore categorized information about the state and test their knowledge with an interactive quiz.

## Features

*   **Dashboard Overview**: A responsive grid layout presenting different categories of Karnataka's heritage (History, Literature, Art & Architecture, Geography).
*   **Detailed Content**: Dive into each category to read comprehensive summaries and learn more about the state's legacy.
*   **Interactive Quiz**: Test your Kannada knowledge with a built-in multiple-choice quiz featuring explanations for correct answers.
*   **Cross-Platform Ready**: Fully responsive design that works seamlessly on mobile devices, tablets, desktop, and the web.

## User Flows

1.  **Exploration**: The user lands on the Home Screen and sees a grid of topics. Tapping on a topic opens the Category Detail screen with full information.
2.  **Assessment**: From the Home Screen, the user can start a quiz. The quiz presents questions sequentially, provides immediate feedback with explanations, and shows a final score upon completion.

## Tech Stack

*   Framework: Flutter
*   Language: Dart
*   State Management: Stateful widgets for the quiz logic
*   Navigation: Named routes via `MaterialApp`
*   Data: In-memory mock data (no backend required)

## Getting Started

To run the application locally:

1.  Ensure you have [Flutter installed](https://docs.flutter.dev/get-started/install).
2.  Clone this repository.
3.  Run `flutter pub get` to install dependencies.
4.  Run `flutter run` to launch the app on your connected device or emulator.
